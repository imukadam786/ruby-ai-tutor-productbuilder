🧠 AI & Diagnostic Engines

Maths Adaptive Engine

  • Skill tree: 6 levels · 11 tiers · 72 atomic skills
  • 3 question templates: concrete / story / symbolic
  • 5 error types: conceptual gap, strategy gap, representation confusion, execution slip, correct
  • Mastery gate: 3 correct in 2+ formats
  • Decision: advance / practice / reteach / backtrack
  • Data: /data/skill-tree.json

Reading Diagnostic Engine (Phonics)

  • 18-task placement (D01–D18): phoneme → fluency
  • Hard Gate 1: D06 CVC encoding <0.8 → Level 3 block
  • 12 error types: ERR_PHONEME_CONF, ERR_BLEND_FAIL, ERR_VOWEL_CONF, ERR_SIGHT_MISS…
  • 5-way decision: ADVANCE / PRACTICE / RETEACH / BACKTRACK / ACCELERATE
  • Choice UI (D01–D04, D06–D07, D11, D15) — avoids STT confusion
  • Voice UI (D05, D08–D10, D12–D14, D16–D18) — full word reading
  • Data: /data/reading-skill-tree.json

    • Missing Building Blocks Summary
    🔐 Authentication No login system. Supabase Auth or Clerk recommended. Required for multi-device sync and billing.
    🗄️ Backend Database All data in browser localStorage. Lost on device switch. Supabase PostgreSQL = direct replacement.
    💳 Payment Gateway Settings billing UI is stub only. Stripe integration needed for subscriptions and school licensing.
    📹 Video Learning "Watch" mode is placeholder. Mux or Cloudflare Stream for low-latency educational video.
    📊 Analytics Platform No behavioural analytics. Posthog (open-source) for funnel analysis and learning drop-off tracking.
    🚨 Error Monitoring No crash reporting. Sentry for production error tracking and alerting on API failures.
    📧 Email Service No transactional email. Resend for welcome emails, weekly progress, subscription receipts.
    📄 PDF Reports Download button in settings does nothing. React PDF library for auto-generated progress reports.
    👩‍🏫 Teacher Dashboard No multi-student view. Teacher role + class management UI needed for school market.
