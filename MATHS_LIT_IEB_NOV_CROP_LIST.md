# Maths Literacy (IEB) November papers — image crop list

Covers the **IEB** Maths Literacy Nov papers (subject slug `maths-literacy-ieb`),
separate from the DBE/CAPS list in `MATHS_LIT_NOV_CROP_LIST.md`.

**All eight papers — 2022, 2023, 2024 and 2025, P1 + P2 each** — were built
**text-first** and are wired and playable now. The sub-questions below reference a
picture. Everything else works as pure text.

Source: `Downloads/Maths Lit/` — `NSC Mathematical Literacy P{1,2} 20XX.pdf` for
2023–2025, `Mathematical Literacy P{1,2} 2022.pdf` for 2022, plus matching Memo PDFs.

## Notes for the cropping pass

- P2 is a maps/plans paper by design — expect to crop ~8 map/plan figures. Print
  the 1.1.4 (a) and 5.1.4 maps at true scale or the ruler-measurement marks can't
  be earned.
- No `diagramUrl`s are set on any sub-question yet, so nothing renders broken in
  the meantime.
- Once cropped, add `"diagramUrl": "<supabase matric-diagrams URL>"` to each
  sub-question in the relevant `data/papers/mlit-ieb-p{1,2}-nov-{2024,2025}.json`
  and re-run `node scripts/regen-paper-index.mjs`.
