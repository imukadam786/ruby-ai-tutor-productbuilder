# Agricultural Sciences P1 — November past papers: image crop list

All 5 papers (`agric-sci-p1-nov-2021` … `-2025`) were built **text-first**. Every
sub-question below refers to a figure in the original DBE question paper. Each was
made self-contained in `questionText` (diagram contents / graph shape / table
values transcribed in words), so the papers are usable as-is. Cropping the
figures listed here would improve the learning experience.

**Priority key**
- **ESSENTIAL** — the answer genuinely depends on seeing the picture (letter-match
  or "which one is shown" questions); the text description is a best-effort stand-in.
- **read-off** — question asks the learner to read a value/point off a graph; a real
  graph would make the exact answer unambiguous.
- **enhance** — fully answerable from the text; a figure just helps comprehension.
